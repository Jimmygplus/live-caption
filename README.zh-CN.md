# Live Caption & Translation

**跟上对话，以自己的方式参与。**

## [打开 Live Caption 网站 →](https://jimmygplus.github.io/live-caption/)

Live Caption 将语音转为可阅读的实时字幕，让参与者也能通过打字加入对话。我们的团队正在为会议、课堂和日常交流构建无障碍浏览器体验，服务于聋人、重听人士以及使用不同语言交流的人群。

## 快速开始

1. 使用电脑端 Chrome 或 Edge 打开网站。
2. 选择 **English captions**（英文字幕）或 **Translate speech to English**（将语音翻译为英文）。
3. 点击 **Try free · 30 min**，允许使用麦克风，即可开始说话。公开试用无需账号、API key、安装软件或填写付款信息。
4. 点击 **Share captions**，通过二维码或加入码邀请参与者。他们可以阅读字幕并发送文字回复。

每次公开试用提供最长 30 分钟的连续连接。停止、刷新或断线都会结束该次连接。公开试用受共享每日额度限制：目前按 UTC 日期计算，每天总计 20 次，每个公网 IP 最多 3 次。

如有推荐码，打开 **API keys**，在直接显示的推荐码输入框中填入，然后点击 **Start with code**。系统会在启动时验证权限。单独配置的不限量推荐码不受应用设置的会话时长或开启次数限制；刷新页面后需重新输入。也可以使用个人 API key，其用量单独计费。

## 主要功能

- 阅读实时字幕，将语音翻译为英文。
- 向参与者共享字幕并接收文字回复。
- 通过 **Audio source** 选择麦克风或浏览器支持的标签页／系统声音。
- 通过 **Custom words** 添加姓名和专业词汇。
- 调整字号，选择 Conversation、Cinema 或 Ticker 阅读模式。
- 回看、修正字幕，并导出 TXT、Markdown 或 SRT 文件。

当前优先优化电脑网页端。音频捕获能力取决于浏览器和操作系统。识别和翻译质量受音频及语言影响，字幕可能需要修正。

## 隐私

音频会发送至语音识别服务以生成字幕。共享字幕房间对字幕和文字回复进行端到端加密；受邀参与者可以阅读这些内容，请妥善保管邀请信息。个人 API key 和用于恢复字幕的记录可能保存在浏览器中。
