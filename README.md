# Live Caption & Translation

**Follow the conversation. Take part in your own way.**

## [Open Live Caption →](https://jimmygplus.github.io/live-caption/)

Live Caption turns speech into readable captions and lets people contribute by typing. Our team is building an accessible browser experience for meetings, classes, and everyday conversations, including people who are Deaf or hard of hearing and people communicating across languages.

## Get started

1. Open the website in desktop Chrome or Edge.
2. Choose **English captions** or **Translate speech to English**.
3. Select **Try free · 30 min**, allow microphone access, and start speaking. No account, API key, installation, or payment details are required for the public trial.
4. Select **Share captions** to invite participants by QR code or join code. Participants can read captions and send typed replies.

Each public trial lasts up to 30 minutes in one continuous connection. Stopping, refreshing, or disconnecting ends that connection. Public access is subject to shared daily availability: currently 20 trials per UTC day overall and 3 per public IP address.

If you have a referral code, open **API keys**, enter it in the visible referral field, and select **Start with code**. Access is verified when you start. Separately configured unrestricted codes remove the app's session-duration and start-count limits. Re-enter your code after refreshing the page. Personal API keys are also optional; their usage is billed separately.

## What you can do

- Follow live captions and translate speech to English.
- Share captions with participants and receive typed replies.
- Choose microphone or supported tab/system audio through **Audio source**.
- Add names and specialist vocabulary through **Custom words**.
- Adjust text size and choose Conversation, Cinema, or Ticker view.
- Review and correct captions, then export TXT, Markdown, or SRT.

Desktop web is the current priority. Audio capture options depend on your browser and operating system. Recognition and translation quality depend on the audio and language; captions may need correction.

## Privacy

Audio is sent to the recognition service to generate captions. Shared caption rooms encrypt captions and typed replies end to end; invited participants can read them, so keep invitations private. Personal API keys and transcript recovery data may be stored in your browser.

## About this repository

This repository contains public product information only. The application source code and development history are maintained in a private repository. You can use the website without access to that repository.

For feedback, open an issue here with your browser, operating system, and steps to reproduce the problem. Do not include API keys, referral codes, private transcripts, or room invitations.
